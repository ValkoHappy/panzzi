# PANZZI

Многоязычный сайт компании по комплектации интерьеров мебелью, освещением, посудой и отделочными материалами. Включает каталог, реализованные проекты и направление запуска бизнеса в Китае.

[Открыть сайт](https://panzzi.com)

![Главная страница PANZZI](docs/images/preview.webp)

## Возможности

- Русская, английская, немецкая и китайская версии с сохранением выбранного языка.
- Каталог с категориями товаров и просмотром изображений.
- Галереи проектов с фотографиями и видео.
- Интерактивные точки на изображениях и отдельный редактор их расположения.
- Переходы в мессенджеры с учётом языка страницы.
- Адаптивная навигация и страницы услуг.

## Структура

| Путь | Назначение |
| --- | --- |
| index.html | Главная страница и проекты |
| catalog.html | Каталог продукции |
| china-entry.html | Услуги по запуску бизнеса в Китае |
| clients.html | Информация для клиентов |
| js/scripts.js | Запуск компонентов главной страницы |
| js/modules/ | Навигация, данные проектов и управление галереями |
| js/ | Каталог, интерактивные точки и локализация |
| style/ | Стили страниц и компонентов |
| content/ | Материалы проектов и каталога, шрифты |
| imgs/ | Изображения интерфейса |
| hotspot-editor.html | Редактор интерактивных точек |

Навигация и галереи подключаются через явные import/export. Версия в URL импортов обновляется вместе с модулями. Переводы хранятся отдельно от логики переключения языка. Каталог и редактор интерактивных точек имеют собственные скрипты. Сайт не требует сборщика или базы данных.

## Локальный запуск

Из корня проекта запустите статический сервер.

```sh
python -m http.server 8080 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8080. Для внешних шрифтов, иконок, аналитики и мессенджеров требуется интернет.

## Обслуживание

- [Работа с интерактивными точками](INTERACTIVE_MAP_GUIDE.md).
- Перед публикацией проверьте главную, каталог и переключение всех четырёх языков на телефоне и компьютере.
- При изменении скриптов обновляйте версию в ссылках на них в HTML.
- CNAME содержит домен сайта для размещения на GitHub Pages.

Фирменные материалы и изображения принадлежат соответствующим правообладателям. Лицензии сторонних шрифтов находятся рядом с файлами шрифтов.
